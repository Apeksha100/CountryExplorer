# 🌍 Country Explorer

Country Explorer is a web application that allows users to search for countries and view detailed information including population, capital, languages, currency, weather conditions, and location on a map. The application fetches real-time data using REST APIs and provides a favorites feature using browser local storage.

## Features

- Search countries by name
- View country details and statistics
- Real-time weather information
- Embedded Google Maps location
- Save and manage favorite countries
- AJAX-based dynamic content loading

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- AJAX (XMLHttpRequest)
- REST Countries API
- OpenWeatherMap API
- Google Maps Embed
- Local Storage API

## Key Concepts Implemented

- AJAX requests using XMLHttpRequest
- REST API integration
- Dynamic DOM manipulation
- Event handling
- Browser Local Storage for favorites
- JSON parsing and serialization
- Google Maps embedding using iframe
